# أمثلة حزمة arabicR

تساعد الحزمة على عرض النص العربي بحروف متصلة ومحاذاة إلى اليمين في الرسوم باستخدام خط Noto Sans Arabic.

بعد تثبيت الحزمة، شغّل المثال من مجلد المستودع:

```sh
Rscript inst/examples/arabic.R
```

يُنشئ المثال صور PNG باستخدام ragg وCairo، وملف PDF باستخدام Cairo، ورسمًا باستخدام ggplot2 عند تثبيته.

```r
library(arabicR)
arabic_png("arabic.png")
arabic_text("مرحباً بالعالم", size = 28)
dev.off()
```

اكتب النص بترتيبه الطبيعي ولا تعكس الحروف يدويًا. يتولى محرك العرض تشكيل الحروف وترتيب النص ثنائي الاتجاه. المحاذاة إلى اليمين تختلف عن اتجاه النص، ولا تغيّر الحزمة ترتيب محاور الرسم أو أعمدة الجداول.

يجب تثبيت الخط على الجهاز. في Debian أو Ubuntu، توفر حزمة fonts-noto-core الخط المطلوب. استخدم إصدارات حديثة من ragg وsystemfonts وtextshaping لتفادي مشكلات الخط البديل عند خلط العربية بالإنجليزية والأرقام.
